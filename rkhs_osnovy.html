1. Функціонал обчислення значення

Нехай ℋ — гільбертів простір функцій f : X → ℝ. Кожній точці x ∈ X відповідає лінійний функціонал обчислення значення δx(f) = f(x). У звичному просторі L² він навіть не означений: елементами є класи еквівалентних функцій, і «значення в точці» не має сенсу. Простір ℋ називають гільбертовим простором з відтворюючим ядром, якщо всі функціонали δx неперервні, тобто |f(x)| ≤ Cx‖f‖ℋ. Звідси одразу випливає, що збіжність за нормою ℋ тягне поточкову збіжність — саме тому з функціями з RKHS зручно працювати в задачах навчання, де нас цікавлять передбачення в конкретних точках.

2. Відтворююче ядро

За теоремою Ріса неперервний функціонал δx зображується скалярним добутком з деяким єдиним елементом kx ∈ ℋ:

f(x) = ⟨f, kx⟩ℋ   для всіх f ∈ ℋ,    k(x, y) := ⟨ky, kx⟩ℋ = ky(x).

Функцію k називають відтворюючим ядром. Вона симетрична і додатно визначена: для будь-яких точок x1,…,xn і чисел ci маємо Σ cicj k(xi, xj) = ‖Σ ci kxi‖² ≥ 0, тобто кожна матриця Грама K = (k(xi,xj)) невід'ємно визначена. Нерівність Коші–Буняковського дає оцінку |f(x)| ≤ ‖f‖ℋ√k(x,x), причому ‖δx‖ = √k(x,x). На вкладці ① зелена крива під курсором — це саме представник kx.

3. Теорема Мура–Ароншайна

Теорема. Для кожної симетричної додатно визначеної функції k : X × X → ℝ існує єдиний гільбертів простір ℋk функцій на X, для якого k є відтворюючим ядром.

Конструкція прозора: беремо лінійну оболонку функцій kx, вводимо на ній скалярний добуток ⟨Σ aikxi, Σ bjkyj⟩ = Σ aibj k(xi, yj) і поповнюємо. Отже, ядро повністю визначає простір, і навпаки. Перевірити, що функція є ядром, означає перевірити невід'ємність спектрів усіх матриць Грама — це ілюструє правий нижній графік вкладки ②.

4. Простір ознак і геометрія

Відображення Φ : X → ℋ, Φ(x) = kx, називають картою ознак: k(x, y) = ⟨Φ(x), Φ(y)⟩. Ядро — це скалярний добуток у (можливо, нескінченновимірному) просторі ознак, обчислений без явного переходу до ознак (так званий kernel trick). Уся геометрія образів точок задається ядром:

‖Φ(x)‖ = √k(x,x),   cos θxy = k(x,y) / √(k(x,x) k(y,y)),   ‖Φ(x) − Φ(y)‖² = k(x,x) + k(y,y) − 2k(x,y).

Для гаусового ядра k(x,x) = 1, тому образ прямої — крива на одиничній сфері нескінченновимірного простору, а далекі точки стають майже ортогональними. Для поліноміального ядра степеня d простір ознак скінченновимірний, dim ℋ = d + 1, і при d = 2 крива Φ(x) = (x², √(2c)·x, c) точно вміщується у три виміри.

6. Теорема про представлення і ядрова регресія

Теорема (про представлення). Розв'язок задачі minf∈ℋ Σ (f(xi) − yi)² + λ‖f‖²ℋ має вигляд f = Σ αi kxi, де α = (K + λI)−1y.

Ідея доведення геометрична: розкладемо f = f∥ + f⊥, де f∥ ∈ span{kxi}. Ортогональна складова не змінює значень у точках даних, бо f⊥(xi) = ⟨f⊥, kxi⟩ = 0, але збільшує норму. Тому нескінченновимірна задача зводиться до лінійної системи розміру n, а квадрат норми розв'язку дорівнює αᵀKα. При λ → 0 отримуємо інтерполянт з мінімальною нормою — ортогональну проєкцію невідомої функції на span{kxi}. Похибку інтерполяції контролює функція потужності P(x) = dist(kx, span{kxi}): |f(x) − s(x)| ≤ P(x)‖f‖ℋ. На вкладці ① вона показана смугою; при λ > 0 це та сама величина √(k(x,x) − kxᵀ(K+λI)−1kx), що в мові гаусівських процесів є апостеріорним стандартним відхиленням.

7. Фізичний зміст ядра

Часто норма RKHS — це енергія: ‖f‖² = ⟨Lf, f⟩L² для деякого диференціального оператора L. Тоді ядро є функцією Гріна, L ky = δy: функція ky — відгук системи на одиничну точкову силу в точці y, а інтерполянт з мінімальною нормою — конфігурація з найменшою енергією, що проходить через задані точки. Для лапласового ядра L = ½(−σ d²/dx² + 1/σ): це пружна струна з натягом σ на пружній основі жорсткості 1/σ, тому інтерполянт має злами у вузлах і експоненційно релаксує між ними.

Гаусове ядро — це ядро теплопровідності. Розв'язок рівняння ut = D uxx з початковою умовою u0 є згорткою з ядром Гауса ширини σ(t) = √(2Dt):

u(x,t) = (4πDt)−1/2 ∫ exp(−(x−y)²/4Dt) u0(y) dy.

Якщо тепло вносять точкові джерела потужності qi, то стан у момент t — це в точності розклад Σ αi kσ(·, xi) з коефіцієнтами αi = qi/√(4πDt), тобто елемент лінійної оболонки ядер — так само, як розв'язок регресії. Дифузія діє як фільтр низьких частот, послаблюючи гармоніку частоти ω у e−Dω²t разів, тому з часом лишаються лише гладкі функції. Цей самий механізм пояснює надзвичайну гладкість елементів RKHS гаусового ядра (вкладка ③, профіль «гребінка»).
