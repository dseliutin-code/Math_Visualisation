Лекція 1. Оператори скінченного рангу та апроксимативна одиниця

Інтерактивні моделі до лекції: ε-сітки, інтерполяційна апроксимативна одиниця в C[0,1], критерії Арцела–Асколі та передкомпактності в ℓᵖ, скінченновимірна апроксимація операторів і фізична симуляція. Клавіші 1–7 перемикають вкладки, Enter застосовує формулу, Пробіл запускає симуляцію.

Скінченні ε-сітки і передкомпактність

Множина A передкомпактна, якщо для кожного ε > 0 її можна накрити скінченною кількістю куль радіуса ε. Тут A ⊂ (ℝ², ‖·‖p) дискретизована, а жадібний алгоритм обирає центри з самої A, доки кожна точка не потрапить у кулю.

ГеометріяФорма кулі залежить від норми: ромб при p = 1, круг при p = 2, квадрат при p = ∞. Кількість куль N(ε) зростає як ε−d, де d — розмірність множини, тому на лог-графіку нахил ≈ 1 для кривої і ≈ 2 для області.

ФізикаN(ε) — кількість «комірок» розміру ε, якими можна з точністю ε закодувати будь-який стан системи; log₂N(ε) біт — це ε-ентропія за Колмогоровим. У нескінченновимірному просторі одинична куля потребує нескінченно багато комірок (теорема Ріса, нижня панель).

Кусково-лінійна інтерполяція — апроксимативна одиниця в C[0,1]

Оператор Lnf = Σk f(tk) φk, tk = k/n, замінює f ламаною через вузли. Він має ранг n + 1, норму ‖Ln‖ = 1 і задовольняє оцінку ‖Lnf − f‖ ≤ ω(f, 1/n). Тому Lnf → f для кожної неперервної f, але не рівномірно на одиничній кулі: функція з ядра Ln дає ‖I − Ln‖ ≥ 1.

ГеометріяLn — проєктор (Ln² = Ln) на (n+1)-вимірний простір ламаних; «шапочки» φk утворюють розбиття одиниці, і Lnf(t) — опукла комбінація значень f у сусідніх вузлах.

ФізикаЦе цифровий запис сигналу: давач вимірює f у n + 1 моменти часу, а пристрій відтворює ламану. Модуль неперервності ω(f, 1/n) — найбільша зміна сигналу між двома вимірами, тобто гарантована похибка відтворення.

Критерій Арцела–Асколі як наслідок теореми 16

Множина A ⊂ C[0,1] передкомпактна тоді й лише тоді, коли вона рівномірно обмежена і рівностепенево неперервна: supf∈A ω(f, δ) → 0 при δ → 0. Еквівалентно (теорема 16): supf∈A ‖Lnf − f‖ → 0. Задайте родину fk, k = 1, …, K, і подивіться, чи «тримаються» ці супремуми при зростанні K.

ГеометріяРівностепенева неперервність означає, що графіки всіх функцій родини мають спільний «запас крутизни»: жодна не може змінитися більше ніж на ε на проміжку довжини δ. Тоді родину з точністю ε описують ламані з фіксованою кількістю ланок.

ФізикаАнсамбль сигналів, усі частоти яких обмежені спільною межею, можна оцифрувати з однією частотою дискретизації; родина sin(kπt) зі зростаючими частотами такого спільного кроку не має.

Передкомпактність у ℓᵖ: рівномірно малі хвости

Координатні проєктори Pnx = (x₁, …, xn, 0, …) утворюють апроксимативну одиницю, тому A ⊂ ℓᵖ передкомпактна ⇔ A обмежена і supx∈A Σk>n |xk|ᵖ → 0. Для заданого ε номер n(ε) показує, скільки координат досить, щоб описати всю множину з точністю ε.

Геометрія«Цеглина» Q = {|xk| ≤ ck} у тривимірному вікні координат (xm, xm+1, xm+2) сплющується при m → ∞: множина «майже лежить» у скінченновимірному підпросторі. Одинична куля в будь-якому вікні виглядає однаково — вона не сплющується ніколи.

Фізикаxk — амплітуди гармонік сигналу, ‖x‖₂² — енергія. Передкомпактність означає, що енергія у високих гармоніках рівномірно мала для всіх сигналів множини.

Діагональний оператор і його наближення операторами скінченного рангу

Нехай T x = (λ₁x₁, λ₂x₂, …) в ℓ², Tn = PnT — оператор рангу ≤ n. Тоді ‖T − Tn‖ = supk>n |λk|. Якщо λk → 0, то Tn → T за нормою і T(B) передкомпактна (теорема 21); при λk = 1/k маємо приклад зауваження 9: границя операторів скінченного рангу, яка сама не має скінченного рангу.

ГеометріяT переводить одиничну кулю в еліпсоїд з півосями |λk|. Компактність — це сплющування еліпсоїда у далеких напрямках; Tn просто «пласко притискає» його до перших n осей. Наведіть мишу на панель: точка x рухається по колу, видно Tx і Tnx.

Фізикаλk — коефіцієнти передачі лінійного фільтра (приладу) для k-ї гармоніки. Компактний фільтр гасить високі частоти, тож на виході досить скінченної кількості каналів; фільтр з |λk| ≥ c > 0 «пропускає все» і компактним не є.

Фізична симуляція: тепловий оператор компактний, хвильовий — ні

Стрижень (або струна) на [0, 1] із закріпленими кінцями. Розклад за модами sin(kπx) перетворює еволюцію на діагональний оператор St з множниками λk(t). Для рівняння теплопровідності ut = κuxx маємо λk(t) = e−k²π²κt → 0: при t > 0 оператор St компактний і майже скінченного рангу. Для хвильового рівняння utt = c²uxx множники cos(kπct) не прямують до нуля — енергія у високих модах не зникає.

ГеометріяПунктирна крива — проєкція Pnu на перші n мод (апроксимативна одиниця, зумовлена базисом). Графік nε(t) показує, скільки мод потрібно для відносної точності ε в L²: для тепла це число швидко падає, для хвилі — ні.

ФізикаДифузія згладжує будь-який початковий профіль: усі стани з обмеженою енергією через час t лежать у передкомпактній множині St(B). Хвиля переносить інформацію без втрат — St(B) залишається «такою ж великою», як B.

1. Передкомпактні множини

Множина N називається ε-сіткою для A, якщо A ⊂ N + εBX; множина A передкомпактна (цілком обмежена), якщо для кожного ε > 0 вона має скінченну ε-сітку. За критерієм Хаусдорфа в банаховому просторі множина компактна тоді й лише тоді, коли вона замкнена і передкомпактна.

Передкомпактні множини обмежені; передкомпактність зберігається при переході до підмножин і замикання, при об'єднанні, сумі, множенні на скаляр і при дії неперервного лінійного оператора (твердження 2).

Лема 3. Якщо для кожного ε > 0 існує передкомпактна Aε з A ⊂ Aε + εBX, то A передкомпактна. Це головний технічний інструмент лекції: наближати можна не скінченними, а передкомпактними множинами.

2. Теорема Ріса

Лема Ріса. Для замкненого підпростору E ≠ X і ε ∈ (0, 1) знайдеться x ∈ SX з dist(x, E) > 1 − ε.
Теорема 5. Одинична куля BX передкомпактна ⇔ dim X < ∞.

У ℓᵖ це видно безпосередньо: ‖ei − ej‖p = 21/p, тож куля радіуса ε < 21/p/2 містить щонайбільше один базисний вектор, а їх нескінченно багато (вкладка 1).

3. Оператори скінченного рангу

T ∈ F(X, Y), якщо T неперервний і dim T(X) < ∞. Еквівалентно, Tx = Σk=1n fk(x) yk з fk ∈ X*. Простір F(X, Y) лінійний і є операторним ідеалом (VTU ∈ F); спряжений T*g = Σ g(yk) fk теж скінченного рангу; T(A) передкомпактна для кожної обмеженої A.

Простір F(X, Y), взагалі кажучи, не замкнений: діагональний оператор diag(1/k) у ℓ² є границею за нормою операторів Tn рангу n, але сам має нескінченний ранг (зауваження 9, вкладка 5).

4. Поточкова збіжність на передкомпактних множинах

Теорема 10. Якщо supn‖Tn‖ < ∞ і Tnx → Tx для всіх x, то збіжність рівномірна на кожній передкомпактній множині.

Доведення — «ε/3»: досить контролювати скінченну ε-сітку. Для банахового X обмеженість норм випливає з теореми Банаха–Штейнгауза. Без неї твердження хибне (вправа 2, простір c00).

5. Апроксимативна одиниця

Послідовність (Tn) ⊂ F(X) з Tnx → x для всіх x. Тоді sup‖Tn‖ < ∞, X сепарабельний, а при dim X = ∞ маємо ‖I − Tn‖ ≥ 1: збіжність до I лише поточкова. У ℓ∞ апроксимативної одиниці немає; Енфло (1973) побудував сепарабельний банахів простір без неї.

Приклади: часткові суми за базисом Шаудера, координатні проєктори Pn у c₀ і ℓᵖ, кусково-лінійна інтерполяція Ln у C[0,1] з оцінкою ‖Lnf − f‖ ≤ ω(f, 1/n).

6. Критерій передкомпактності

Теорема 16. Нехай (Tn) — апроксимативна одиниця в банаховому X. Множина A передкомпактна ⇔ A обмежена і supx∈A‖Tnx − x‖ → 0.

Обидві умови суттєві: куля обмежена, але не має рівномірної збіжності; пряма {λe₁} має рівномірну збіжність, але необмежена.

Наслідки. У ℓᵖ (1 ≤ p < ∞): обмеженість і supx∈AΣk>n|xk|ᵖ → 0; у c₀: supx∈A supk>n|xk| → 0; у C[0,1]: теорема Арцела–Асколі (рівномірна обмеженість і рівностепенева неперервність). Цеглина Гільберта {|xk| ≤ 1/k} компактна в ℓ².

7. До компактних операторів

Теорема 21. (a) Якщо ‖Sn − S‖ → 0, Sn ∈ F, то S(BX) передкомпактна. (b) Якщо S(BX) передкомпактна і Y має апроксимативну одиницю (Tn), то ‖TnS − S‖ → 0.

Оператори з передкомпактним S(BX) називаються компактними. У просторах з апроксимативною одиницею це в точності замикання F(X, Y) за нормою. Тепловий оператор etΔ — компактний, хвильовий — ні (вкладка 6).
